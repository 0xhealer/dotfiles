# Contributing

Maintained by [0xhealer](https://github.com/0xhealer). Contributions are welcome.

1. Fork [0xhealer/dotfiles](https://github.com/0xhealer/dotfiles) and create a branch from `main`.
2. Keep changes focused; follow `.editorconfig` (and run `stylua .` for Lua code).
3. Open a pull request using the provided template.

Found a bug or have an idea? [Open an issue](https://github.com/0xhealer/dotfiles/issues/new/choose).

By contributing you agree that your contributions are licensed under the [MIT License](LICENSE).
